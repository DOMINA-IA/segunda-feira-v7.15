## Arquitetura — 4 camadas oficiais

### BUILD (construção)
- **Agent Studio** — visual low-code, exporta para ADK
- **Agent Development Kit (ADK)** — code-first, sub-agentes em grafo
- **Agent Garden** — biblioteca de templates (financial, code modernization, invoice, research)
- **Multimodal Streaming** — áudio/vídeo ao vivo via WebSocket
- **Native Ecosystem Integrations** — BigQuery, Pub/Sub, CRMs
- **Batch & Event-driven Agents**

### SCALE (escala)
- **Agent Runtime 2.0** — cold start sub-segundo
- **Long-running Agents** — autônomos por dias com estado persistente
- **Agent Sandbox** — ambiente isolado para código/bash/browser
- **Agent-to-Agent Orchestration** — delegação entre agentes (complexa, generativa, determinística)
- **Agent Memory Bank** — memória de longo prazo + Memory Profiles
- **Agent Sessions** — Custom Session IDs mapeiam para CRM/DB

### GOVERN (governança — diferencial competitivo)
- **Agent Identity** — ID criptográfico único por agente, zero-trust em cada passo
- **Agent Registry** — catálogo central de agentes/ferramentas/skills
- **Agent Gateway** — políticas centralizadas, suporta MCP e A2A
- **Model Armor** — proteção contra prompt injection e data leakage
- **Agent Anomaly Detection** — estatística + LLM-as-judge
- **Agent Threat Detection** — reverse shells, IPs maliciosos
- **Agent Security Dashboard** — Security Command Center

### OPTIMIZE (otimização)
- **Agent Simulation** — testes contra usuários sintéticos
- **Agent Evaluation** — multi-turn autoraters em tráfego ao vivo
- **Agent Observability** — visualização de reasoning
- **Agent Optimizer** — clusterização automática de falhas
