# BAVI — Modelo Linchpin + MIFG (Receita Recorrente)

Modelo operado pelo ecossistema Fábio Soares. MIFG (presente gratuito com cartão cadastrado) gera MAIS faturamento que o evento principal. Fluxo: Challenge/Webinário → MIFG R trial (cartão) → cobrança automática R/mês → webinário gravado semanal → oferta high-ticket. Russell Brunson: 5 tipos de produto recorrente: software, newsletter, suplemento, membership, box mensal. O 'login' (acesso a dashboard/agente) é o mecanismo de retenção — cliente não cancela porque já usou o produto. Laxute faturou RM em 2 anos com Blackbird (SaaS email) usando esse modelo. Benchmark: MIFG > receita do evento. Aplicar: Kit Squad DOMINA R trial → R/mês com dashboard de agentes. CORTEX link: [bavi-12-pillars] [bavi-pit-vendas]
