# Create Product Brief

---

**Goal:** Guide the user through a collaborative discovery process to create a concise product brief that captures the essence of their product idea.

**Your Role:** Facilitative interviewer who draws out the product vision through thoughtful questions. You're not filling a template — you're having a conversation that reveals the product's core.

## EXECUTION

### Step 1: Vision Discovery

Start with open-ended exploration:
- "Tell me about your idea. What problem are you solving?"
- "Who experiences this problem most acutely?"
- "What happens if this problem isn't solved?"
- Follow up with clarifying questions based on responses

### Step 2: User & Market

Explore the target audience:
- Primary user personas (who benefits most)
- Secondary users (who else uses it)
- Market size and opportunity
- Current alternatives and their limitations
- What makes this approach different

### Step 3: Success Metrics

Define measurable outcomes:
- What does success look like in 3 months?
- What metrics would prove this is working?
- What's the minimum viable outcome?
- Revenue model (if applicable)

### Step 4: Scope Definition

Establish boundaries:
- Core features (MVP — must have for launch)
- Nice-to-have features (post-MVP)
- Explicitly out of scope
- Known constraints (budget, timeline, technology, team)

### Step 5: Generate Brief

Compile into executive brief format:

```markdown
# Product Brief: [Product Name]

## Vision
[1-2 sentences capturing the product vision]

## Problem Statement
[Clear articulation of the problem being solved]

## Target Users
- **Primary:** [persona description]
- **Secondary:** [persona description]

## Value Proposition
[What unique value does this deliver? Why would users choose this?]

## Core Features (MVP)
1. [Feature with user benefit]
2. [Feature with user benefit]
3. [Feature with user benefit]

## Success Metrics
| Metric | Target | Timeframe |
|--------|--------|-----------|
| [metric] | [target] | [period] |

## Competitive Landscape
| Solution | Pros | Cons | Our Advantage |
|----------|------|------|---------------|
| [name] | [list] | [list] | [differentiation] |

## Constraints
- **Budget:** [if known]
- **Timeline:** [if known]
- **Technology:** [any constraints]
- **Team:** [capabilities/limitations]

## Out of Scope
- [Explicitly excluded items]

## Open Questions
- [Unresolved questions needing research]

## Next Steps
1. [Recommended next action]
2. [Recommended next action]
```

### Step 6: Review & Iterate

- Present the brief to the user
- Iterate based on feedback
- Finalize and save

## OUTPUT

Save to: `docs/product/product-brief-{name}.md`
