## Prompt Mestre Universal

Usar este template para qualquer dos 20 modelos:

```
MODELO: [número] — [nome do modelo]
PRODUTO/SERVIÇO: [o que comunicar]
PÚBLICO-ALVO: [avatar do cliente ideal]
PLATAFORMA: [onde publicar]
DURAÇÃO: [Xs]
ASPECTO: [9:16 | 16:9 | 1:1]

DIREÇÃO DE FOTOGRAFIA:
- Enquadramento: [close-up / medium shot / wide / alternado]
- Movimento de câmera: [estático / pan horizontal / tracking / dolly in-out / crane]
- Iluminação: [natural / estúdio / cinematográfica / low-key / neon]
- Speed ramping: [normal / slow-mo em momentos-chave / time-lapse em transições]
- Cor: [warm / cold / desaturated / high contrast / brand colors]
- Transições: [corte seco / morph / zoom / match cut / whip pan]

ÁUDIO:
- Voz: [narração / talking head / voice over / sem voz]
- Música: [estilo musical / BPM sugerido / energia]
- SFX: [whoosh em transições / click em dados / ambient]

ESTRUTURA DO ROTEIRO:
[00:00-00:03] HOOK
> Visual: [descrição da cena]
> Áudio: [texto falado]
> Direção: [movimento de câmera + iluminação]

[00:03-00:XX] DESENVOLVIMENTO
> Visual: [descrição da cena]
> Áudio: [texto falado]
> Direção: [movimento de câmera + iluminação]

[00:XX-00:XX] CTA
> Visual: [descrição da cena]
> Áudio: [texto falado]
> Direção: [movimento de câmera + iluminação]

REGRAS FIXAS:
1. Consistência visual entre takes (mesmo grading, mesma energia)
2. Hook nos primeiros 1.5s (visual + áudio sincronizados)
3. Cada corte deve ter propósito (não cortar por cortar)
4. CTA visual + verbal (mostrar E falar a ação)
5. Música casa com ritmo das transições
```

## Modelos Detalhados (Top 5 para DOMINA.IA)

### Modelo 6: Performance Ad (Meta Ads)
```
[00:00-00:02] HOOK — Frase de parar scroll + close-up rosto com emoção
[00:02-00:05] PROBLEMA — Dor do avatar + b-roll ou dado impactante
[00:05-00:12] SOLUÇÃO — Como resolve + prova rápida (screenshot, resultado)
[00:12-00:15] CTA — Ação clara + scarcity visual (timer, vagas)

Direção: Cortes rápidos (0.5-2s), close-ups dominantes, texto na tela reforçando áudio
Câmera: Alternância close-up ↔ medium shot a cada corte
Cor: Alto contraste, brand colors em destaque
```

### Modelo 3: Explainer (Educacional)
```
[00:00-00:05] HOOK — Pergunta provocativa + visual intrigante
[00:05-00:15] CONTEXTO — Por que isso importa (dado ou história)
[00:15-01:30] EXPLICAÇÃO — Passo a passo com visuais de suporte
[01:30-02:00] EXEMPLO — Caso real ou demonstração
[02:00-02:30] RECAP + CTA — Resumo de 3 pontos + próximo passo

Direção: Medium shots, ritmo calmo, motion graphics para conceitos
Câmera: Estático com zoom lento, alternando talking head + b-roll
Cor: Clean, profissional, fundo neutro
```

### Modelo 4: UGC (Orgânico)
```
[00:00-00:02] HOOK — "Gente, vocês não vão acreditar..." + selfie câmera frontal
[00:02-00:10] HISTÓRIA — Experiência pessoal autêntica
[00:10-00:20] RESULTADO — O que mudou (mostrar, não contar)
[00:20-00:25] RECOMENDAÇÃO — "Se você [dor], testa isso" + CTA sutil

Direção: ZERO produção aparente. Câmera frontal, iluminação natural, sem edição pesada
Câmera: Selfie mode, movimentos naturais (não estabilizado demais)
Cor: Sem grading (raw, autêntico)
```

### Modelo 17: Case Study
```
[00:00-00:05] HOOK — Resultado impactante ("De R$3K para R$30K em 90 dias")
[00:05-00:20] ANTES — Situação inicial do cliente
[00:20-00:50] PROCESSO — O que foi feito (3 etapas visuais)
[00:50-01:10] DEPOIS — Resultados com dados
[01:10-01:30] CTA — "Quer o mesmo resultado?"

Direção: Storytelling visual, dados em motion graphics, depoimento do cliente
Câmera: Mix de entrevista (medium) + b-roll de resultados
Cor: Professional, warm tones
```

### Modelo 20: Manifesto
```
[00:00-00:03] ABERTURA — Frase de posicionamento forte
[00:03-00:15] CRENÇA — O que acreditamos (valores da marca)
[00:15-00:25] VISÃO — O futuro que estamos construindo
[00:25-00:30] CTA — Convite para fazer parte

Direção: Cinematográfico, épico, emocional
Câmera: Wide shots + slow dollys + close-ups em momentos de emoção
Cor: Cinematic grading, alto contraste
Música: Épica, crescendo até o CTA
```
